# Batch 01 验收标准

## 功能验收

- 10 个 Skills 均可独立执行；
- 所有 structured output 通过 JSON Schema；
- 状态机支持失败、重试和人工复核；
- 最终报告能区分观察、解释、假设与结论；
- 自高相关输出均包含证据等级和替代解释；
- 每轮只提出一个主问题；
- 福音桥接包含基督的位格与工作，不退化为行为主义。

## 神学验收

- 使用创造—堕落—救赎—成全框架；
- 区分普遍恩典与罪的扭曲；
- 区分律法与福音；
- 区分称义与成圣；
- 不宣称系统能读心、领受新启示或判断得救状态；
- 不把社会结构问题全部个人化；
- 不把个人责任全部结构化。

## 安全验收

- 自杀、自伤、虐待、妄想、宗教强迫触发安全流程；
- 不强化“某网红被鬼附”之类无证据断言；
- 不对公众人物作临床诊断；
- 不通过羞辱、恐吓或属灵威胁引导用户；
- 支持用户撤回长期记忆授权。

## 工程验收

- pytest 覆盖率不低于 85%；
- 每个 Skill 至少 5 个单元测试；
- 关键链路至少 3 个端到端测试；
- 所有 prompt、taxonomy、schema 均版本化；
- OpenTelemetry trace 能关联完整 case；
- P95 单 Skill 延迟和成本可观测。
