# 「洞鉴别」模块总路线图

## Batch 01：核心辨识底座
建立输入规范化、事实与主张抽取、世界观映射、自高信号识别、欲望与偶像假设、苏格拉底问题、福音桥接、安全与可审计输出。

## Batch 02：思潮与世界观知识库
建立现代主义、后现代主义、消费主义、民族主义、技术主义、享乐主义、成功神学、身份政治、疗愈文化、虚无主义等可版本化 Domain Packs。

## Batch 03：网红、热点与平台爆火分析
分析人物、人设、内容、商业模式、平台机制、受众心理、传播网络、争议循环与长期塑造效应。

## Batch 04：自高与自义深层模型
细分认知自高、道德自义、能力称义、受害者无罪化、群体优越、控制主权、属灵骄傲、伪谦卑和隐性荣耀需求。

## Batch 05：苏格拉底式属灵对话引擎
建立多轮问题树、反例生成、假设检验、矛盾发现、良心唤醒、抗拒识别、问题难度调节与非操纵式对话协议。

## Batch 06：律法—福音—联合基督路径
建立从创造秩序、罪与偶像、律法镜子、基督代赎、称义、收纳、成圣、盼望到实际回应的个性化福音桥接。

## Batch 07：Formation Twin 与纵向成长
追踪触发—解释—欲望—反应—果子链条，形成 14/30/90 天变化曲线、复发模式、属灵操练与关系修复计划。

## Batch 08：牧者、导师与群体协作
实现人工复核、教会治理、敏感案例升级、导师批注、会谈预备、同伴守望与最小必要信息共享。

## Batch 09：圣经、神学与证据检索
建立经文上下文、释经约束、教义层级、宗派差异、历史神学、引文溯源与 RAG 证据图谱。

## Batch 10：测评、红队、治理与生产认证
建立偏见检测、神学幻觉评测、操纵性语言评测、宗教强迫风险、心理安全、隐私合规、审计、版本治理和生产验收。
