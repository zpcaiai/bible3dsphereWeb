## 2. Formation Twin 不是人格复制

Formation Twin 是对用户已授权数据的结构化模型：

```text
FormationTwin = {
  active_patterns,
  active_gospel_truths,
  common_triggers,
  interpretation_habits,
  dominant_desires,
  functional_saviors,
  emotional_body_signals,
  action_tendencies,
  relationship_effects,
  fruit_evidence,
  relapse_risks,
  repair_capacity,
  practice_transfer,
  uncertainty
}
```

它不是：

- 用户完整人格；
- 灵魂数字副本；
- 对未来行为的确定预测；
- 得救状态判定器；
- 心理或精神疾病诊断器。

## 3. 事件链

每个 Formation Event 包含：

```text
context
-> trigger
-> automatic_interpretation
-> desire_or_fear
-> active_belief
-> emotion
-> body_signal
-> chosen_action
-> avoided_action
-> relationship_effect
-> immediate_reward
-> delayed_cost
-> gospel_truth_recalled
-> repair_action
-> outcome
```

并区分：

- 用户直接自述；
- 同伴或导师反馈；
- 系统推断；
- 未确认假设。

## 5. 纵向窗口

### 14 天：可见性与启动
评估：
- 是否能识别触发；
- 是否能暂停；
- 是否能命名欲望；
- 是否开始使用福音真理；
- 是否完成第一个修复行动。

### 30 天：重复与迁移
评估：
- 新反应是否在多个场景出现；
- 是否减少旧模式自动化；
- 是否更快恢复；
- 是否能接受反馈；
- 是否形成群体支持。

### 90 天：稳定与关系果子
评估：
- 跨压力情境的稳定性；
- 关系中他人是否观察到变化；
- 复发后恢复是否更快；
- 是否不再依靠单一功能性救主；
- 福音身份是否进入工作、家庭、教会和冲突。

## 6. 复发状态机

```text
STABLE
-> VULNERABLE
-> TRIGGERED
-> OLD_PATTERN_ACTIVE
-> CONSEQUENCE_VISIBLE
-> AWARENESS
-> RETURN_TO_GOSPEL
-> REPAIR
-> REINTEGRATED
```

可进入：

- `UNACKNOWLEDGED`
- `SHAME_SPIRAL`
- `AVOIDANCE`
- `SAFETY_HOLD`
- `HUMAN_SUPPORT_REQUIRED`

## 7. 成长不是线性曲线

系统禁止把成长建模为：

```text
每天都比昨天更好
```

更合理的是：

```text
成长 =
  觉察更早
+ 旧反应持续时间缩短
+ 伤害强度降低
+ 修复速度加快
+ 更能接受帮助
+ 在压力中仍能回到福音
```

## 8. 福音身份迁移

身份迁移不是只会复述：

> 我在基督里被接纳。

而是验证该真理是否改变：

- 解释：失败不再等于无价值；
- 欲望：不再必须被看见；
- 行动：能委派、道歉和休息；
- 关系：不再通过控制获得安全；
- 复发：跌倒后回到基督而非羞耻螺旋；
- 盼望：未完成不再等于绝望。

## 9. 关系修复验证

道歉不等于修复完成。系统检查：

- 是否准确命名伤害；
- 是否承担责任而不辩解；
- 是否停止相关行为；
- 是否尊重对方边界；
- 是否有可观察补偿；
- 是否接受信任恢复需要时间；
- 是否有第三方或教会问责；
- 是否在后续压力中保持改变。

## 10. 安全边界

- 宗教强迫：禁止增加认罪次数和隐藏罪搜索；
- 创伤与虐待：安全高于关系恢复；
- 危机：停止常规 Formation 计划；
- 公众人物：不得建立私人 Formation Twin；
- 未成年人：需要额外同意和数据最小化；
- 用户可导出、纠正、删除或暂停纵向追踪。
