# 属灵星球「洞鉴别」Batch 07
## Formation Twin 与纵向生命塑造系统

Batch 07 将前六批的世界观、属灵假设、苏格拉底对话和福音路径，转化为可持续追踪的 Formation Twin：

```text
触发
-> 解释
-> 欲望
-> 信念
-> 情绪与身体
-> 行动
-> 关系影响
-> 短期奖赏
-> 长期果子
-> 福音身份回应
```

系统重点实现：

- 日常事件采集；
- 触发—解释—欲望—信念—行动—关系—果子链；
- 个人 Formation Twin 状态快照；
- 14/30/90 天成长评估；
- 复发与诱因识别；
- 道歉、边界和关系修复验证；
- 福音身份迁移验证；
- 操练是否真正迁移到压力情境；
- 牧者、导师和用户共同复核；
- 数据最小化、同意、删除和心理安全。

## 核心原则

1. **不把属灵生命压缩成总分。**
2. **不把一两次失败视为身份倒退。**
3. **不把外在顺服自动等同内心更新。**
4. **不把情绪平静自动等同属灵成熟。**
5. **不把认罪次数当作成长指标。**
6. **成长证据必须包含压力情境中的迁移。**
7. **福音身份不是主观口号，而要观察其如何改变解释、欲望、行动和关系。**
8. **复发是需要理解和应对的事件，不是称义被取消。**
9. **系统不代替教会、牧者、心理治疗或危机支持。**
