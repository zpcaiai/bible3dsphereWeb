# 释经标准

## 最小释经单元

系统回答前至少获取：

- 当前经节；
- 前后段落；
- 全书结构位置；
- 文体；
- 说话者和受众；
- 关键重复词；
- 逻辑或叙事功能。

## 释经输出顺序

1. 文本观察；
2. 语法与结构；
3. 历史和文学背景；
4. 原始受众意义；
5. 正典与救赎历史；
6. 教义关系；
7. 当代应用；
8. 局限与其他主要解释。

## 应用限制

当代应用必须经过：

```text
Original Meaning
-> Enduring Theological Principle
-> Covenant / Redemptive-Historical Location
-> Contemporary Analogy
-> Pastoral Application
```

不得从古代叙事细节直接跳到个人预言或成功公式。
