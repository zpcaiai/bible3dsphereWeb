# 版权与内容权利标准

## 文本状态

- `public_domain`
- `open_license`
- `licensed_internal`
- `user_owned`
- `quotation_only`
- `metadata_only`
- `prohibited_for_embedding`
- `prohibited_for_generation`

## 规则

1. 每个文档必须有 rights_status。
2. 不明版权默认不允许全文嵌入。
3. 可只保存元数据和短引用。
4. 用户上传资料只在其授权范围内使用。
5. 导出时不得附带无权再分发的全文。
6. 经文译本必须记录版本和授权。
7. 原文批判文本、词典和形态数据库必须记录许可证。
8. 系统不得把版权文本作为隐藏语料长期保存而无授权。
