# 属灵星球「洞鉴别」Batch 09
## 圣经、神学、释经与证据知识库系统

Batch 09 为前八批提供可审计的圣经、神学、历史与释经证据底座。

核心链路：

```text
用户问题 / 属灵假设 / 福音路径
-> 经文定位
-> 章节与全书上下文
-> 文体与历史背景
-> 原文词汇与语法
-> 正典与救赎历史
-> 圣经神学
-> 系统教义
-> 历史神学
-> 宗派差异
-> 引文与来源审计
-> 经文误用检测
-> 可审计 RAG 证据图谱
```

## 核心原则

1. 经文不得脱离段落、全书、正典与救赎历史。
2. 原文字义不得由 Strong 编号或词根联想替代。
3. 词义由语境、语法、语料和作者用法共同约束。
4. 单节经文不能自动建立完整教义。
5. 教义必须区分核心共识、传统差异和次要观点。
6. 历史神学不是最高权威，但能防止时代性失忆和重复异端。
7. 所有引文必须有来源、版本、页码或定位信息。
8. RAG 输出必须能追踪到原始证据节点和转换过程。
9. 系统不得生成“神直接告诉我”的新启示。
10. AI 释经必须标记不确定性，并允许牧者和学者复核。
11. 圣经译本、词典、注释书和论文必须遵守版权与授权。
12. 公开领域文本、已授权文本和用户自有资料必须明确区分。
