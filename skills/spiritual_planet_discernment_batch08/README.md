# 属灵星球「洞鉴别」Batch 08
## 牧者、导师、教会群体与人工复核协作系统

Batch 08 将前七批生成的辨识报告、属灵假设、苏格拉底对话、福音路径和 Formation Twin，
连接到真实教会中的牧者、导师、小组同伴、长执治理和专业转介流程。

核心链路：

```text
用户授权
-> 角色与权限解析
-> 最小必要信息选择
-> 会谈预备
-> 牧者/导师批注
-> 人工复核与纠错
-> 敏感案例升级
-> 共同体支持计划
-> 问责与治理
-> 后续修复和纵向复核
```

## 核心原则

1. 用户不是被管理的对象，而是有尊严、有同意权的主体。
2. 牧养协作不得自动获得 Formation Twin 全量数据。
3. 默认采用最小必要信息，而非“知道越多越好”。
4. 导师、小组长、牧者、长执、专业人员拥有不同权限。
5. 属灵假设不能自动成为纪律证据。
6. AI 报告不能替代牧者判断、教会程序或专业评估。
7. 敏感案例必须有清晰的升级、暂停和外部转介路径。
8. 教会纪律必须有事实、程序、申诉、利益冲突回避和保护弱者机制。
9. 虐待、性侵、未成年人和危机案件不得只在内部“属灵处理”。
10. 用户应能查看、纠正、撤回和审计共享记录。
