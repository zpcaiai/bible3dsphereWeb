# Batch 08 验收标准

## 权限与同意
- 默认拒绝；
- 访问必须有具体目的；
- 角色、数据等级、用户授权、关系、冲突和有效期共同决定；
- 用户可以撤回授权；
- 安全例外必须记录理由和复核。

## 最小必要共享
- 不共享完整Formation Twin；
- 只共享完成当前任务必要的字段；
- 脱敏第三方信息；
- 访问有过期时间；
- 再共享规则明确；
- 用户可查看共享记录。

## 协作
- 会谈预备只有一个优先问题；
- 导师可以不同意AI假设；
- 用户修正不被覆盖；
- 小组长不承担调查、诊断和纪律；
- 牧者不自动获得L2/L3全量访问。

## 敏感案例
- 未成年人、虐待、危机、性侵和法律风险进入R3；
- 正式治理与申诉进入R4；
- 利益冲突必须回避；
- 可能需要外部报告时不得只内部处理；
- 具体法律义务必须由地区策略和合格人员判断。

## 教会治理
- AI不能决定纪律；
- 有事实、回应、保护、回避和申诉；
- 饶恕不等于恢复职位；
- 恢复不等于取消后果；
- 举报人不得被报复；
- 犯罪和安全问题不被属灵化。
