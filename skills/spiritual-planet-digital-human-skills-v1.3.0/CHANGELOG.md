# Changelog

## 1.3.0 — 2026-09-23

- Expanded Bible digital-human scope from 24 to 100 character packs without changing the MetaPerson + LiveSpeak + LiveKit runtime.
- Added 76 standard-alpha characters spanning primeval history, patriarchs, Exodus/conquest, judges, monarchy, prophets, exile/return, the Gospels and the early church.
- Every new character includes the same 7-file contract: character, Persona, recommended questions, Truth Set, relationships, Avatar/Voice and review notes.
- Each new pack contains at least three character-specific scripture-grounded truth cases plus appearance/voice uncertainty and no-new-revelation guardrail cases.
- Added `docs/14-core-100-character-catalog.md` and upgraded `examples/characters.index.yaml` to 100 entries.
- Kept Jesus outside the ordinary free-chat Core 100; reserve a future higher-grounding Jesus Experience Mode.

## 1.2.0 — 2026-09-23

- Expanded from 4 to 24 alpha-ready Bible digital-human character packs.
- Added Adam, Noah, Abraham, Sarah, Isaac, Jacob, Joseph, Joshua, Samuel, Saul, Solomon, Elijah, Isaiah, Jeremiah, Daniel, Ruth, Esther, Mary (mother of Jesus), John and Barnabas.
- Kept the MetaPerson + LiveSpeak + LiveKit runtime unchanged; expansion is configuration/content driven.
- Added dynamic all-character validation based on `examples/characters.index.yaml`.
- Added `scaffold_character_pack.py` for low-cost future character expansion.
- Added Core 24 catalog and per-character Truth Sets, relationship evidence, Avatar/Voice specs and review gates.

## 1.1.0 — 2026-09-23

- Added Alpha character packs for Moses, David, Peter and Paul.
- Added Avatar/Voice specs, Persona rules, recommended questions, relationship evidence, Truth Sets and review notes for each.
- Expanded David from the minimal v1.0 example to the same release contract as the other three characters.
- Added package-wide character validation and first-four release guidance.
- Bumped package version to 1.1.0.
