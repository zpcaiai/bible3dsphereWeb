# Character Asset Review Checklist

- [ ] Character ID matches canonical registry.
- [ ] Portrait/GLB is an artistic reconstruction, not presented as verified likeness.
- [ ] Clothing and visual language fit the intended era.
- [ ] GLB loads from production-like CDN URL.
- [ ] Viseme blendshapes are present and lip-sync works.
- [ ] Bust framing is acceptable on desktop and mobile.
- [ ] Texture/model size is within performance budget.
- [ ] Voice is approved for intended language/persona.
- [ ] Voice is not labeled as historical/authentic recording.
- [ ] Asset version is immutable and rollbackable.
- [ ] Legal/license review recorded where required.
