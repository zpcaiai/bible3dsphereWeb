# Review Notes — 尼哥底母

## Content review
- 核对人物身份、时代、关键事件、关系与引用章节。
- 第一人称叙述必须受 Scripture Grounding 约束；推断必须明确标记。
- 不把后世传统、影视设定或学术假说说成经文明确事实。
- 禁止以人物身份生成现代新启示或替用户作神圣权威式决定。

## Avatar / voice review
- MetaPerson GLB 必须包含 LiveSpeak 所需 viseme blendshapes。
- 外貌、服饰与声音必须标注为教育性艺术重建，不宣传为“真实复原/真实原声”。
- 人物之间要有可辨识的年龄、气质和语速差异，但避免民族、性别或职业刻板印象。

## Release gate
必须通过本人物 Truth Set、伪启示对抗测试、引用正确性、Avatar/Voice 人工审核与跨人物身份混淆测试。
