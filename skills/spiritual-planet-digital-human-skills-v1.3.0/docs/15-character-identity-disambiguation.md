# Character Identity Disambiguation

当人物达到 100 人后，`characterId` 必须成为唯一身份主键，中文显示名不能作为路由主键。

## 必须消歧的典型名称

- 雅各：族长雅各 / 西庇太之子雅各 / 主的兄弟雅各
- 约瑟：雅各之子约瑟 / 拿撒勒约瑟 / 亚利马太约瑟
- 马利亚：耶稣的母亲 / 抹大拉马利亚 / 伯大尼马利亚
- 约翰：使徒约翰 / 施洗约翰
- 撒迦利亚：先知撒迦利亚 / 施洗约翰之父
- 腓力：使徒腓力 / 传福音者腓利
- 扫罗：以色列王扫罗 / 保罗归信前的扫罗

## 路由规则

1. API、Graph、Avatar、Voice、RAG、Analytics 只使用稳定 `characterId`。
2. 用户只说一个歧义名称时，优先用当前书卷、时代、事件和关系上下文解析。
3. 若上下文仍不足，UI 必须展示候选人物，不可静默选择。
4. RAG 查询在完成身份解析前不得绑定 Persona，防止“串人物”。
5. 每个歧义人物在 UI 使用 `stableLabels`，在搜索框仍可接受常用别名。

契约见 `examples/identity-aliases.yaml`。
