# Core 100 Bible Digital-Human Catalog

本目录定义属灵星球 v1.3 的 100 人数字人物范围。运行时仍只有一套 MetaPerson + LiveSpeak + LiveKit + Bible Persona Engine；人物差异由 Character Pack 驱动。

## 分层

- **Deep Alpha (24)**：v1.2 已有较深 Truth Set / Persona / 关系配置。
- **Standard Alpha (76)**：v1.3 新增，采用同一 7 文件发布契约，至少 3 个角色特定事实测试 + 外貌不确定性 + 禁止新启示测试。

## 重要边界

- **耶稣不计入这 100 个普通自由聊天数字人物。** 如后续实现，应使用更高约束的 `Jesus Experience Mode`，以福音书文本、场景和经文解释为核心，而不是普通 Persona Chat。
- 神、圣灵不作为普通数字人角色。
- 100 人均必须通过 Scripture Grounding、引用校验、伪启示拒绝与 Avatar/Voice 艺术重建声明。
