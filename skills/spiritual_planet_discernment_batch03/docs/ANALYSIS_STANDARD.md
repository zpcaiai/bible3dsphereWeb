# 网红与爆火分析标准

## 1. 公平呈现
先描述其真实能力、社会贡献和受众合理需要，再讨论扭曲与偶像化风险。

## 2. 人物不等于人设
至少区分：
- verified_identity
- self_claimed_identity
- performed_persona
- audience_symbol
- commercial_brand
- analyst_hypothesis

## 3. 公开证据优先
只分析公开、相关、必要的材料；不鼓励挖掘私人生活。

## 4. 不以结果证明正当
流量、财富、影响力、转化率都不能证明内容为真或手段为善。

## 5. 不做单因果归因
爆火至少应评估内容、平台、网络、时机、受众和偶然性。

## 6. 不把受众污名化
每个受众群体必须包含：
- 合理需要；
- 所处压力；
- 被吸引原因；
- 风险；
- 可替代的健康路径。

## 7. 属灵辨识边界
“偶像、自高、替代救恩”属于牧养性解释，必须标为假设；不得宣告神对某人的隐藏审判。
