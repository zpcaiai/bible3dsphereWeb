## 核心原则

爆火不是单因果事件，而是一个多层耦合系统：

```text
人物真实能力
+ 公共人设
+ 内容叙事
+ 商业激励
+ 平台可供性
+ 受众欲望
+ 网络传播
+ 争议反馈
+ 时机与偶然性
= 可观察的爆火结果
```

系统不得：

- 声称知道公众人物的内心动机；
- 把相关性写成算法因果；
- 依据一次视频诊断人格或精神疾病；
- 把热度等同于真实、良善或神的认可；
- 把所有粉丝视为同一种人；
- 在没有公开证据时声称违法、诈骗或操纵；
- 用宗教语言进行羞辱、诽谤或灵魂定罪。
