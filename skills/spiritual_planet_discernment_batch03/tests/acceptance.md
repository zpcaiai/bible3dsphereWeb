# Batch 03 验收标准

## 功能
- 20 个 Skills 可发现、可版本化；
- 九段分析链均有独立输入输出；
- 支持跨平台、时间切片和复合思潮；
- 支持人物—人设分离；
- 支持传播图与争议状态机；
- 支持长期果子“观察/自述/预测”分离。

## 证据
- 每项高风险结论绑定 EvidenceRef；
- 隐藏动机、内部算法、未披露收入不得作为事实；
- 批评传播不得统计为支持传播；
- 重复转载不得虚增来源独立性；
- 所有因果解释至少含替代模型。

## 神学
- 承认普遍恩典和合理社会需要；
- 自高、偶像、替代救恩只作为牧养性假设；
- 分析者自己也接受律法镜照；
- 福音桥接以基督和恩典为中心；
- 不以流量作为神认可或神审判的证据。

## 安全
- 禁止开盒、人肉、骚扰和网暴；
- 禁止无证据违法定性；
- 禁止临床人格诊断；
- 禁止判定得救状态或被鬼附；
- 未成年人和法律敏感案例必须人工复核；
- 高风险健康、法律和财务内容进入专项安全流程。

## 工程
- pytest 全部通过；
- 关键纯函数覆盖率目标 >= 85%；
- 所有 Schema 有验证测试；
- 所有 Skill 有 Guardrails、Evidence、Acceptance Tests；
- Trace 可关联 case、skill、model、prompt、evidence 和人工覆盖。
