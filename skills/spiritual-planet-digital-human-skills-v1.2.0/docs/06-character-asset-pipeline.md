# 06 — Character Asset Pipeline

## Required artifacts per published character

- `character.yaml`
- reviewed portrait
- versioned GLB with visemes
- voice profile
- persona system prompt
- recommended questions
- truth set
- asset review checklist

## Review gates

### Historical/visual
- period-appropriate clothing direction;
- regionally plausible appearance without claiming certainty;
- no obviously modern objects;
- no reused identical face for multiple unrelated characters unless intentionally stylized.

### Technical
- GLB loads;
- textures resolve;
- bust framing is acceptable;
- viseme/lip animation functions;
- model size fits delivery budget;
- CDN cache/version behavior verified.

### Domain
- no UI wording that calls the face a “true reconstruction”;
- voice labeled/understood as dramatized synthesis;
- persona facts map to sources.
