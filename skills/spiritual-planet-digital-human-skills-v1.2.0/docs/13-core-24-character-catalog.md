## Expansion principle

- 新人物原则上只增加角色包，不修改实时运行时。
- 每个角色统一包含 7 个交付物：character、persona、questions、truth-set、relationships、avatar-voice、review-notes。
- 新角色必须先通过 Truth Set、引用、伪启示、身份混淆和 Avatar/Voice 审核。
- 耶稣暂不作为普通自由聊天数字人加入 Core 24；相关体验应使用更严格的独立设计。
