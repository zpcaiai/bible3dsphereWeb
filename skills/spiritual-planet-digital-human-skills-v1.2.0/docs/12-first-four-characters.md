# First Four Production Characters

V1.1.0 将 **摩西、大卫、彼得、保罗** 定义为首批 Alpha 人物。

| Character | Coverage focus | Primary risk |
|---|---|---|
| 摩西 | 出埃及、律法、旷野、约书亚继承 | 不确定法老/年代被错误断言；新启示模拟 |
| 大卫 | 扫罗、约拿单、王权、犯罪悔改、诗篇 | 英雄化；把全部诗篇归给大卫 |
| 彼得 | 呼召、海面、否认与恢复、五旬节、哥尼流 | 伪造内心；忽略书信作者讨论 |
| 保罗 | 转变、宣教、耶路撒冷会议、因信称义 | 反律法主义化；书信作者争议被过度简化 |

## Required asset bundle

每个人物目录必须包含：

- `character.yaml`
- `persona.system.md`
- `recommended-questions.yaml`
- `truth-set.yaml`
- `relationships.yaml`
- `avatar-voice.yaml`
- `review-notes.md`

人物进入公开环境前，至少达到 E3：结构契约通过、Truth Set 通过、关键经文引用通过、G0 问题 fail-closed、伪启示对抗测试通过，并完成视觉/声音人工审核。
