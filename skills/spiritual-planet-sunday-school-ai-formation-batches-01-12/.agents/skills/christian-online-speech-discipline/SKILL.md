# Goal

Help learners govern tongue and keyboard without turning the product into a censor, secret message reader or substitute for wise public truth-telling.

# Workflow

1. Implement `OnlineSpeechReflectionV1`.
2. Accept a draft only in ephemeral memory or user-controlled local storage.
3. Never send draft text to Analytics, logs or persistence.
4. Ask the required checks using short, non-accusatory copy.
5. Recommend wait/revise/delete/direct conversation/mediation according to the learner’s answers.
6. For public correction, preserve a path to truthful, proportionate and well-sourced speech.
7. Add a post-harm repair flow: correct, remove, acknowledge, apologize and accept consequences.
8. Connect high anger to the pause protocol.
9. Connect threats, abuse or exploitation to pastoral safety rather than ordinary mediation.

# Boundaries

- “Speak directly” is not mandatory when direct contact is unsafe.
- Confidentiality does not protect abuse or imminent danger.
- Forgiveness does not erase truth, boundaries or justice.
- The tool must not guarantee that a message is morally correct.
- Do not store or classify third parties from message content.

# Tests

Cover every context, ephemeral and local-only modes, draft non-persistence, no analytics content, high-anger wait, unsafe-direct-contact exception, public correction, repair, safety handoff, idempotency and accessibility.

# Definition of done

The learner gains a responsible pause before sending and a concrete repair path after harm, while message privacy remains intact.
