# Batch 10 Implementation Checklist

## 仓库发现

- [ ] 确认真实模块、路由、设计系统和测试命令
- [ ] 确认身份、租户、权限和监护人/教师关系来源
- [ ] 确认内容审核和 S0–S3 安全门
- [ ] 形成文件级实施图和迁移计划

## 契约与数据

- [ ] 实现全部 JSON Schema 的原生类型与 trust-boundary 验证
- [ ] 拒绝未知字段并添加有效/无效 fixtures
- [ ] 添加迁移、唯一约束、索引、所有权与版本字段
- [ ] 实现删除、导出、撤销共享和保留策略
- [ ] 验证 Analytics denylist 与日志脱敏

## 产品与内容

- [ ] 实现路由、状态、Loading/Empty/Error/Retry
- [ ] 导入课程、实践、场景和策略种子且保持 review 状态
- [ ] 实现 Feature Flag、i18n、响应式与无障碍
- [ ] 实现教师/家长/学习者权限边界
- [ ] 实现内容审核、版本、发布和回滚

## 安全与神学

- [ ] 所有情境必须虚构、非露骨、可跳过且经过相应神学/牧养/儿童安全审核；不得要求学习者重演真实创伤。
- [ ] 运行时只保存版本、节点、选择和状态，不保存原始自由文本，不根据路径建立人格、风险或属灵画像。
- [ ] 选择节点不得用羞耻、倒计时、预设唯一“敬虔答案”或隐藏惩罚操控学习者。
- [ ] 后果是带不确定性的可能果子，不是预言；不得生成未来行为、救恩或道德价值评分。
- [ ] 经文/恩典介入必须同时保留真理、责任、修复和帮助；禁止廉价恩典、纯定罪或“神告诉你”式私人神谕。
- [ ] 苏格拉底分支必须允许跳过、不确定和替代解释，禁止强迫继续、诱导认罪和采集私密历史。
- [ ] 真实安全披露必须退出角色扮演；教师不得公开羞辱、承诺绝对保密或做取证式追问。
- [ ] 合成基准只证明工程行为，不得宣称真实属灵成长、临床效果或生产安全已获证明。

## 验证

- [ ] 运行技能包静态校验
- [ ] 运行 lint/typecheck/unit/integration/migration
- [ ] 运行 E2E、键盘、屏幕阅读器、移动端和 reduced-motion 测试
- [ ] 运行安全、隐私、红队和内容审核测试
- [ ] 记录真实命令、退出码、失败和阻断项
