This package follows the OpenAI Codex repository-skill convention current at package generation time:

- repository skills under `.agents/skills/<skill-name>/SKILL.md`;

- explicit invocation through `$skill-name`;
- repository rules through layered `AGENTS.md`;
- routing and behavior evals with positive, edge and negative cases.
