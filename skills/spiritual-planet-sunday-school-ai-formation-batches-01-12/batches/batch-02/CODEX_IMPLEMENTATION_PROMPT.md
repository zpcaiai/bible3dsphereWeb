5. lint、typecheck、unit、integration、e2e、a11y 和 migration 测试命令。

- Digital Sabbath
- 睡眠、休息、运动、饮食节律和安全禁食边界
- 延迟满足、无聊承受、单任务、情绪暂停、网络言语、责任承担

C. 复盘与治理
- Today / Check-in / Review
- pause / resume / simplify / replace / complete / archive
- 导出、删除、自愿分享和撤销分享
- 失败后优先降低难度、暂停和寻求支持，不使用羞耻化连续打卡

- 不诊断成瘾、ADHD、抑郁或其他疾病；
- 不把低屏幕时长等同于敬虔；
