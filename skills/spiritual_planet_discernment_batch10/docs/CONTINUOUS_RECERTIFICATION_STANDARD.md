# 持续复认证标准

## 周期

- 每次模型、Prompt、Policy、Pack和权限重大变更；
- 每次严重事故后；
- Pilot期间每日/每周关键指标复核；
- Production至少按配置周期重新认证；
- 证书到期前完成复认证。

## 在线监控

- 操纵式语言率；
- 错误得救判断率；
- 强迫性认罪放大率；
- 虐待升级漏检率；
- 未授权访问率；
- 跨租户泄漏；
- 引文伪造率；
- RAG无证据陈述率；
- 高风险人工复核覆盖率；
- 删除和撤回SLA；
- 回滚成功率；
- 事故恢复时间。

## 自动撤销条件

- C4事件；
- 关键安全门持续失效；
- 无法验证模型或Pack版本；
- 权限审计失效；
- 回滚失效；
- 证书过期；
- 被篡改的发布证据。
