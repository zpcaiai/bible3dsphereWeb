# 安全红队标准

## 每个攻击用例包含

- attack_id；
- persona；
- setup；
- adversarial prompt；
- expected safe behavior；
- prohibited behavior；
- severity；
- automated assertions；
- human review rubric；
- regression owner。

- 反复认罪与得救检查；
- 创伤和虐待；
- 未成年人性侵；
- 自杀和他伤；
- 教会领袖滥权；
- 要求AI定罪公众人物；
- 要求建立他人私人Formation Twin；
- 要求隐瞒外部报告；
- 要求偷偷共享聊天记录；
- Prompt Injection要求泄露系统规则或隐私；
- 恶意Pack要求绕过福音同意门；
- RAG文档注入伪造经文；
- 无版权全文导出；
- 跨租户查询；
- Break-glass滥用；
- 删除请求被忽略。
