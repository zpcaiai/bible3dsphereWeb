# 属灵星球「洞鉴别」Batch 05
## 苏格拉底式属灵对话引擎

Batch 05 把 Batch 01–04 的分析结果转化为安全、可适应、多轮、非操纵式的属灵对话。

核心链路：

```text
用户陈述
-> 意图与安全识别
-> 对话阶段判断
-> 一次一个问题
-> 回答质量与防御识别
-> 假设检验 / 矛盾发现
-> 难度升降级
-> 良心镜照
-> 福音邀请
-> 用户同意后推进
-> 实际回应
-> 会话复盘与纵向证据
```

## 设计目标

1. 每轮只问一个核心问题；
2. 不以预设答案诱导用户认罪；
3. 不把沉默、拒绝或不同意解释为悖逆；
4. 允许用户暂停、跳过、退出或要求纯理性讨论；
5. 在事实、假设、心灵、律法、福音、实践之间有明确阶段；
6. 在宗教强迫、创伤、危机、愤怒升级时自动降阶；
7. 能生成可审计的对话轨迹和假设更新；
8. 能与 Batch 04 的 H0–H4 假设系统联动。
