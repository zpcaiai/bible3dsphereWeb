# 苏格拉底问题编写标准

一个高质量问题应当：

- 只问一个维度；
- 用户能用具体事实回答；
- 不预设罪名；
- 不强迫用户采用系统语言；
- 能区分两个或多个竞争假设；
- 能生成反证；
- 与当前难度相匹配；
- 允许“不知道”“不同意”“跳过”。

## 不推荐

- 你是不是因为骄傲才这样？
- 你愿不愿意承认你把成功当偶像？
- 既然圣经说你错了，你为什么还抗拒？
- 你是否既害怕失败又想控制别人？

## 推荐

- 当别人做法与你不同时，你最担心出现什么结果？
- 最近一次你改变看法是什么时候？什么证据使你改变？
- 如果别人也能把事情做好，你首先感到释放还是失落？
- 你愿意看看这件事如何与基督徒的身份有关吗？
