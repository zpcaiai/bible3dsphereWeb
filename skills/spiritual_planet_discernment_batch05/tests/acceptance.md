# Batch 05 验收标准

## 对话
- 每轮最多一个核心问题；
- 问题只涉及一个维度；
- 用户可回答“不知道、不同意、跳过、暂停”；
- 对话阶段和难度合法；
- 不在事实不足时直接进入心灵定罪。

## 假设检验
- 每个问题声明其检验目的；
- 回答可以支持、削弱或否证假设；
- 不同意不等于防御；
- 矛盾必须先允许语境、时间和定义差异解释；
- 任何假设都不能形成自证循环。

## 福音
- 福音探索前有明确同意；
- 用户拒绝后继续提供非宗教分析；
- 不使用恐吓、羞辱和社会压力；
- 包含基督位格与工作、恩典身份、悔改和信心；
- 不退化为行为主义。

## 安全
- 宗教强迫停止普通追问；
- 创伤激活降低难度或暂停；
- 危机进入安全流程；
- 用户边界被尊重；
- 不判断得救状态或被鬼附；
- 不以抗拒圣灵解释普通不同意。

## 工程
- 20 个 Skills 可发现；
- 8 个问题包可加载；
- 所有 Schema 可解析；
- pytest 全部通过；
- Trace 保存阶段、难度、问题、回答、假设影响、同意和安全事件。
