# 属灵星球「洞鉴别」Batch 06
## 律法—福音—联合基督路径引擎

Batch 06 将 Batch 01–05 的辨识、假设与对话结果，连接到一条完整而个性化的福音路径：

```text
创造秩序
-> 罪与偶像
-> 律法功用
-> 基督位格与代赎
-> 因信称义
-> 被神收纳
-> 与基督联合
-> 圣灵成圣
-> 教会共同体
-> 终末盼望
```

系统目标不是只让用户“感觉好一点”或“更加努力”，而是帮助用户看见：

- 人是谁；
- 人的问题是什么；
- 基督是谁、做了什么；
- 人如何因信得着祂；
- 新身份如何产生新生命；
- 成圣为何依赖圣灵与群体；
- 苦难、失败和死亡如何置于复活与新创造盼望中。

## 核心边界

系统不得：

- 把福音缩减为成功、疗愈、道德或政治方案；
- 把悔改解释为赚取赦免；
- 把成圣表现作为称义根据；
- 把心理疾病、创伤或现实压迫仅解释为个人罪；
- 声称系统知道谁被拣选、谁一定得救或失落；
- 以宗派争议冒充福音核心；
- 用恐吓、羞辱或群体压力强迫回应；
- 在用户拒绝后继续福音劝服。
