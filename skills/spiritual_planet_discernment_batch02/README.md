# 属灵星球「洞鉴别」Batch 02：现代思潮与世界观 Domain Packs

本批次建立可直接装载、组合、版本化和评测的现代思潮知识包。它接入 Batch 01 的 `worldview-frame-mapper`、`pride-signal-detector`、`socratic-question-planner` 与 `gospel-bridge-builder`。

## 内置能力

- 32 个基础 Domain Packs；
- 6 个主题集群；
- 统一 JSON Schema；
- 语义匹配与复合思潮分析；
- 每包独立的神学分析规则；
- 每包 22 个分阶段苏格拉底问题；
- seeker / Christian formation / defensive 三类福音桥接；
- 安全、反稻草人、反读心和非强迫约束；
- 自动化质量验证与测试样例；
- Python Loader、Registry、Matcher 与 CLI 骨架。

## 基本原则

Domain Pack 不是给人贴标签，而是提出可检验的解释模型：

```text
观察 -> 主张 -> 世界观假设 -> 替代救恩 -> 自高假设
     -> 反证 -> 苏格拉底追问 -> 福音桥接 -> 生命回应
```

任何思潮都必须先识别其中的真实社会问题与普遍恩典，再分析绝对化风险。
