# Domain Pack Authoring Standard

每个包必须包含：

1. 公平定义与范围边界；
2. 至少三项真实洞见或普遍恩典；
3. 核心人论、问题论、救恩论与终局；
4. 至少三项自高/自义假设；
5. 欲望—偶像链；
6. 平台、经济或权力机制；
7. 经文主题与上下文警告；
8. 十一阶段苏格拉底问题树；
9. 至少三类福音桥接；
10. 正向信号、排除条件与反证；
11. 宗教强迫、心理安全与公共人物保护规则；
12. 至少五个自动化测试。

禁止：

- 把复杂传统写成单一邪恶动机；
- 把政治偏好冒充圣经唯一立场；
- 使用不可证伪分类；
- 以“魔鬼的诡计”替代具体证据分析；
- 根据单句或单个关键词判断人格；
- 把福音桥接写成操纵性销售漏斗。
