# Batch 02 验收标准

## Pack 完整性

- 30 个 Pack 全部可被 Registry 加载；
- 每个 Pack 均有 pack.json、SKILL.md、socratic_tree.json、gospel_bridges.json、tests.json；
- 所有 JSON 通过 Schema；
- ID 唯一、版本明确、依赖 Batch 01；
- 每包至少三项普遍恩典、三项自高假设、三项反证或排除规则。

## 对话质量

- 每包采用 adaptive single-question；
- 先 steelman 后批判；
- 不使用不可证伪问题；
- 非基督徒进入福音桥接前须同意；
- 用户防御升高时回到澄清而非加压。

## 神学质量

- 区分创造之善、堕落扭曲、替代救恩和终局；
- 福音必须包含基督的位格与工作；
- 不把政治或文化偏好冒充唯一圣经立场；
- 不用经文标签取代上下文解释；
- 不把所有社会问题个人化，也不取消个人责任。

## 安全质量

- 不读心、不判断得救、不宣告附鬼或神秘启示；
- 不对公共人物作临床或灵魂诊断；
- 宗教强迫与焦虑案例转入恩典、安全和人工复核；
- 用户可拒绝福音对话或结束追问。
