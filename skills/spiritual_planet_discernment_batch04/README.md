# 属灵星球「洞鉴别」Batch 04
## 自高、自义与隐性荣耀深层模型

Batch 04 将九类常见自高模式做成可组合、可证伪、可纵向验证的“属灵诊断假设系统”：

1. 认知自高
2. 能力称义
3. 道德自义
4. 受害者无罪化
5. 控制主权
6. 群体优越
7. 属灵骄傲
8. 伪谦卑
9. 弥赛亚自我形象

这里的“诊断”不是临床诊断，也不是读取人心，而是：

```text
公开观察 / 用户自述
-> 可替代解释
-> 初步假设
-> 苏格拉底检验
-> 纵向果子验证
-> 保留、降级或撤销假设
```

## 核心设计

- **Observation First**：先记录可观察行为和原话；
- **Hypothesis, Not Verdict**：只输出假设，不宣判人格；
- **Composable**：一个案例可同时命中多个模式；
- **Counter-Evidence Required**：每个假设都必须列反证；
- **Longitudinal**：单次表现不能等同稳定品格；
- **Self-Mirror First**：优先帮助用户自省，避免把系统变成定罪他人的工具；
- **Law and Gospel**：律法揭示自我称义，福音把身份重新安置在基督里；
- **Pastoral Safety**：宗教强迫、过度认罪、创伤和危机优先进入安全流程。
