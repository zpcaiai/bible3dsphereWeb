# Batch 04 验收标准

## 模型
- 9 个 Pack 全部可加载；
- 每个 Pack 含受造之善、信号、替代解释、反证、问题树和福音桥接；
- 支持多假设组合，不强制单标签；
- 支持 masking、reinforcing、alternating 和 context-dependent。

## 证据
- 单次事件最高 H1；
- 无纵向证据最高 H2；
- H0–H2 不写成稳定人格结论；
- 每个假设有反证条件；
- 可以降级或否证，不允许只升不降。

## 神学
- 区分恩赐与称义；
- 区分公义与自义；
- 区分责任与控制主权；
- 区分真实受伤与道德豁免；
- 区分谦卑与自我否定；
- 基督而非自我修炼是最终救主。

## 安全
- 不做临床诊断；
- 不判断得救状态；
- 不声称被鬼附；
- 不把不同意视为骄傲证据；
- 宗教强迫停止加深认罪；
- 创伤案例使用创伤知情路径；
- 公众人物稳定人格结论必须人工复核。

## 工程
- pytest 全部通过；
- 所有 Schema 可解析；
- Pack Registry 无重复 ID；
- 所有 Skill 有 Guardrails 和验收要求；
- Checksum 与 ZIP 完整性通过。
