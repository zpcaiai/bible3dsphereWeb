# 模块蓝图：AI时代心意更新与家庭门训

## 1. 模块使命

帮助成人、父母、儿童青少年与主日学教师，在后现代和AI媒介环境中形成：

- 对基督的真实归属；
- 可持续的注意力与身体治理；
- 对即时满足、身份表演、色情、消费与算法操纵的分辨；
- 不把思考、祷告、判断、关系与责任外包给AI的能力；
- 以福音、恩典、真理、群体和使命为中心的家庭门训；
- 从外在限制逐步走向内在治理。

## 2. 非目标

模块不得：

- 把AI或互联网本身描述成邪恶实体；
- 把身体、情绪、性欲或技术使用本身视为罪；
- 将某一种家庭设备规则绝对化为普遍神命；
- 替代地方教会、牧者、医生、心理专业人员或儿童保护机构；
- 为父母提供秘密监控、强制读取隐私或羞辱性管教工具；
- 用积分、连续打卡或排行榜制造属灵优越感；
- 对未成年人作诊断、定罪或自动化纪律处分。

## 3. 四条课程轨道

### A. 成人自我治理

领域：
- 注意力
- 身体节律
- 即时满足
- 性与虚拟亲密
- 情绪与真理
- 身份与个人品牌
- AI认知外包
- 知识骄傲
- 网络言语
- 舒适崇拜与承担

### B. 父母与家庭门训

领域：
- 父母先自我治理
- 家庭注意力生态
- 家庭礼仪
- 家庭AI公约
- 真实关系与共同生活
- 成功偶像辨识
- 认罪、后果与修复文化
- 分阶段交还治理权

### C. 儿童青少年形成

年龄带：
- 0–6：依恋、模仿、身体节律、故事
- 7–12：习惯、叙事、基础分辨
- 13–15：身份、性、同伴、真实问题
- 16–18：自由、责任、判断、使命

### D. 教师与牧养支持

能力：
- 课程选择与备课
- 年龄适配
- 讨论带领
- 情境演练
- 家庭作业
- 观察记录
- 安全转介
- 内容复核

## 5. Batch 01 页面范围

必须实现：

- 主日学 Tab 中的模块卡片
- `/sunday-school/ai-formation` 模块入口页
- 四条课程轨道卡片
- 模块介绍、适用对象、神学定位与安全说明
- 开始学习 CTA
- 教师入口 CTA（有权限时显示）
- 加载、空、错误与重试状态
- 移动端与键盘可用
- 中文文案与 i18n key

可以用占位状态但必须有类型和路由契约：

- 课程列表
- 课时详情
- 家庭AI公约生成器
- 自评与成长计划
- 教师控制台

## 6. 数据最小化

Batch 01 不采集：

- 具体色情内容明细
- 未成年人私密聊天
- 精确地理位置
- 医疗诊断
- 政治身份
- 宗派身份（除非用户主动选择课程配置且明确用途）
- 设备全部浏览历史

## 7. 成功标准

- 用户能够从主日学 Tab 发现模块；
- 能理解模块不是反技术课程；
- 能选择正确轨道；
- 神学内容能标明权威层级；
- 未成年人风险内容会触发安全门；
- 模块可在现有项目栈中运行；
- 自动测试覆盖导航、Schema、安全门和无障碍基础要求。
