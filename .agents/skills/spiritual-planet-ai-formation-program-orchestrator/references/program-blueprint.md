## 安装

```bash
cp -R .agents/skills /path/to/spiritual-planet/.agents/
```

把 `AGENTS.md.snippet` 合并到仓库根目录或主日学模块目录的 `AGENTS.md`，然后阅读并执行：

```text
CODEX_IMPLEMENTATION_PROMPT_ALL.md
```

## 实施原则

- 先运行仓库发现，再按依赖顺序实施，不另建平行应用。
- 每个 Batch 都可以作为独立垂直切片发布；总编排器负责跨批次兼容、迁移、Feature Flag 和认证。
- 所有课程种子保持人工审核状态；任何高风险、儿童、性、牧养、神学、隐私和发布判断不得由模型自动批准。
- 静态包校验只证明 Skills、资源、Schema、评测和内部交叉引用一致；真实仓库仍必须运行原生编译、迁移、E2E、安全、无障碍、内容审核和部署验收。
